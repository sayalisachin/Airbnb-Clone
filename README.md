# 🏡 Airbnb Clone (Frontend Only)

A responsive, modern Airbnb-inspired frontend application built to showcase UI/UX skills, component architecture, and real-world product flows. This project replicates the core visual experience of Airbnb, including listing pages, category browsing, modals, filtering, and booking UI components.

---

## ✨ Features

### 🔍 Core Interface
- Fully responsive Airbnb-style layout  
- Dynamic category filters (Beach, Rooms, Farms, etc.)  
- Search bar with modal-based location/date/guest selection  
- Listing cards with hover effects, wishlist icon, and price preview  
- Dedicated listing details page (images, description, amenities, calendar UI)

### 🧭 Navigation & UI Components
- Global navbar + mobile navigation  
- Reusable components (modals, buttons, inputs, icons, image components)  
- Clean, consistent design system  
- Smooth animations and transitions  

### 🧩 State & Logic
- Local state handling for modals and filters  
- URL-based query params for filtering listings  
- Custom hooks for UI state management  
- Mock data integrated for listings & categories  

---

## 🛠️ Tech Stack

- **Framework:** React  
- **Styling:** TailwindCSS    
- **State Management:** React hooks 
- **Icons:** React Icons / custom SVG
